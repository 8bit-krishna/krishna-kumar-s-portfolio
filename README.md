# Krishna's portfolio

A responsive, dependency free personal portfolio site. It uses plain HTML, CSS, and JavaScript, so there is no build step.

## Run locally

1. Open `index.html` in a browser.
2. For a local web server, run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Personalize before sharing

The current site includes the name, email address, GitHub profile, education, skills, project details, and resume supplied by Krishna. Review these details before sharing the site publicly. Update `index.html` if anything changes.

The design uses Google Fonts when online and falls back to system fonts when they are unavailable. No analytics, external scripts, or backend services are included.
